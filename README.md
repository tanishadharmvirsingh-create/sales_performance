Sales Performance Forecasting

📌 Project Overview

Sales Performance Forecasting is a data analysis and machine learning project that analyzes historical sales data to identify important business trends and predict future sales performance.

The project uses Python, data analysis, visualization, and machine learning techniques to understand sales patterns and generate predictions.

🎯 Objectives

- Analyze historical sales data.
- Identify sales trends and patterns.
- Analyze sales by category and region.
- Identify top-performing products.
- Study relationships between numerical variables.
- Build a model for sales prediction.
- Compare actual sales with predicted sales.
- Visualize the results using charts.

🛠️ Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- GitHub

📊 Dataset

The project uses the "train.csv" dataset stored inside the "data" folder.

The dataset contains historical sales information used for exploratory data analysis, visualization, and sales prediction.

📈 Analysis and Visualizations

The project includes the following visualizations:

- Actual vs Predicted — compares actual sales with model predictions.
- Category Sales — shows sales performance across product categories.
- Correlation Heatmap — displays relationships between numerical variables.
- Monthly Sales Trend — shows changes in sales over time.
- Region Sales — compares sales performance across different regions.
- Top 10 Products — identifies the products with the highest sales.

🤖 Machine Learning

A machine learning model is used to predict sales performance based on the available historical data.

The model is trained using the dataset and its predictions are evaluated by comparing predicted values with actual sales values.
